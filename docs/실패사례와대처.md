# 학습 실패 사례와 대처

## 1. 실험 목표

작은 Transformer로 이동·비용 사전학습 → BFS 길찾기 SFT → 비용 절감 RL을 실습합니다. 각 단계가 끝나면 예측과 실제 이동을 확인합니다. 현재 환경은 일반 바닥 비용 1, 늪 비용 4인 결정적 미로이며 RL은 PPO입니다. 규칙과 구현 구조는 [학습설계](학습설계.md)에 있습니다.

## 2. 환경과 학습 방식 변경

| 순서 | 실패·문제 | 적용한 대처 | 관찰 결과 |
|---|---|---|---|
| 미끄러짐·구멍 환경 + GRPO | SFT 도착률 40.6%에서 GRPO 35.7%로 하락. 충돌과 시간초과 증가 | SFT 학습 확대, GRPO 구간별 검증, 시작 SFT를 선택 후보에 포함 | 이후 실행에서 SFT 49.2%, GRPO 52.3%. 추락률은 18.0%에서 20.1%로 증가 |
| 과제 변경 | 미끄러짐을 끄면 SFT가 쉽게 도착하고, 켜면 추락이 성능을 크게 좌우 | 벽·늪이 있는 결정적 미로로 변경. BFS는 최단 이동, RL은 최소 비용을 목표로 분리. GRPO를 PPO·GAE로 교체 | BFS·Dijkstra는 모두 도착하지만 학습 모델은 벽 충돌과 반복으로 실패 |
| 첫 미로 PPO | SFT 도착률 58.3%, 마지막 PPO 41.7%, 검증 선택 62.5%. 평균 충돌 수 각각 22.750·27.396·21.583 | 아래의 행동·SFT·PPO 로직 보정 | 최신 테스트에서 충돌은 모두 0, 반복에 의한 실패는 남음 |

## 3. 적용한 로직 보정

- **행동:** 인접 벽과 지도 밖 방향을 제외합니다. 학습·평가·실행에 같은 규칙을 적용합니다.
- **SFT 정답:** BFS 거리를 한 칸 줄이는 모든 행동을 정답으로 인정합니다. 동등한 최단 경로 행동을 오답으로 처리하던 문제를 줄였습니다.
- **SFT 보정:** 100회마다 학습 지도 32개에서 모델을 실행하고, 최단 경로에서 벗어난 위치의 학습 가중치를 4배로 올립니다.
- **가치 학습:** 가치 손실이 행동 Transformer를 바꾸지 않도록 표현을 detach합니다. 첫 rollout으로 가치 출력을 먼저 학습하고 정책·가치 학습률을 분리합니다.
- **정책 유지:** 시작 SFT를 고정 기준으로 두고 KL 손실을 추가합니다.
- **보상:** BFS 거리 변화에 따른 보상 shaping을 추가합니다. 평가에는 원래 환경 보상과 비용을 사용합니다.
- **진단·선택:** 학습·검증 행동 정확도, 벽 확률, 반복률을 기록합니다. 검증 도착률을 우선하고 동점이면 평균 보상으로 모델을 선택합니다.

## 6. 남은 원인 확인과 다음 대처

현재 입력은 전체 지도와 현재 위치이며 방문 이력은 없습니다. 실행·평가는 argmax이므로 같은 위치로 돌아오면 같은 행동을 선택해 반복이 지속됩니다. PPO 학습에서는 행동을 샘플링합니다.

다음 항목은 아직 적용하지 않았습니다.

1. 위 실패 seed에서 위치별 네 행동 확률을 기록하고, 같은 체크포인트의 argmax와 샘플링 실행을 비교합니다. 실행 방식 문제와 학습된 길찾기 오류를 구분합니다.
2. 모델 선택에 지도별 `SFT 성공 → PPO 실패`와 반대 방향의 변화 수를 기록합니다. 현재 선택은 전체 도착률·평균 보상만 비교합니다.
3. 학습·검증 지도의 도착률과 반복률을 같은 방식으로 비교해 RL 과적합 여부를 확인합니다. 현재 SFT의 학습·검증 행동 정확도 차이는 작지만, 이 수치만으로 PPO 과적합을 판정할 수는 없습니다.
4. SFT의 막다른 길 탈출·되돌아온 뒤 다른 방향 선택을 우선 점검합니다. 실패 위치 보정이 해당 오류를 학습시키는지 확인한 뒤 지도 표현이나 방문 이력 입력 변경을 검토합니다.
