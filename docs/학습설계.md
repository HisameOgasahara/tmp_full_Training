# 미끄러운 미로의 규칙과 단계별 학습 목표

## 1. 목적과 실행 순서

지도 전체와 현재 위치를 보고 상하좌우 중 한 행동을 골라 목표에 도착하는 Transformer를 학습합니다. 사전학습에서 이동 규칙을 익히고, SFT에서 목표로 가는 기본 행동을 익힌 뒤, GRPO에서 실제 성공·추락·이동 비용을 반영합니다. RL은 이 흐름의 post-training에 포함됩니다.

각 단계의 학습 셀을 실행하고 바로 아래 평가 셀에서 모델을 직접 사용하세요. 사전학습은 다음 위치 예측 화면, SFT는 이동 화면, GRPO는 SFT와 나란히 이동하는 화면으로 확인합니다. 세 단계가 끝나면 최종 테스트를 실행합니다.

## 2. 환경 규칙

| 항목 | 기본 설정 |
|---|---|
| 지도 크기 | 5×5 또는 7×7 |
| 관측 | 전체 지도, 지도 크기, 현재 위치. 목표는 지도 타일로 표시 |
| 행동 | 위·오른쪽·아래·왼쪽 |
| 출발점·목표 | 무작위 지도는 왼쪽 아래 출발, 오른쪽 위 목표 |
| 벽·지도 밖 | 제자리에 남고 충돌 비용 적용 |
| 구멍 | 이동 즉시 실패 종료 |
| 목표 | 이동 즉시 성공 종료 |
| 미끄러짐 | 출발 칸이 미끄러운 바닥이면 지정 방향 70%, 양옆 방향 각각 15% |
| 시간 제한 | 최대 64회 행동 |
| 이동 보상 | 매 행동 −0.01 |
| 추가 보상 | 목표 +1, 구멍 −1, 충돌 −0.02 |

확률과 보상은 `configs/t4.json`의 `environment`에서 바꿉니다. 충돌 없이 10회 이동 후 도착하면 총 보상은 0.90입니다. 도착 없이 64회 이동하고 충돌도 없다면 −0.64입니다. 모델은 매 이동 후 실제 위치를 다시 받습니다.

지도는 벽·구멍·미끄러운 칸을 무작위로 배치하고, 미끄러짐을 끈 조건에서 출발점부터 목표까지 안전한 경로가 있는 지도를 채택합니다. 실행 화면의 **위험한 지름길 예시**는 상단의 미끄러운 길 아래에 구멍을 둔 고정 지도입니다. 학습·평가에는 각 split에서 생성한 무작위 지도를 사용합니다.

## 3. 공유 모델과 입력

무작위 초기화한 4층 causal Transformer decoder를 모든 단계에서 공유합니다. 기본 설정은 차원 128, attention head 4개, MLP 배수 4, 파라미터 809,157개입니다.

| 작업 | 입력 | 예측 |
|---|---|---|
| 환경 예측 | 작업 토큰, 지도 크기, 지도 타일, 현재 위치, 행동, 질의 토큰 | 다음 위치 토큰 |
| 행동 선택 | 작업 토큰, 지도 크기, 지도 타일, 현재 위치, 질의 토큰 | 4개 행동 토큰 중 하나 |

타일·위치·행동을 69개 토큰으로 표현합니다. 작은 지도는 최대 크기까지 벽 토큰으로 채우며, 위치는 최대 크기 격자의 행·열을 한 인덱스로 표현합니다. 입력은 최대 54토큰이고 마지막 질의 토큰의 출력으로 예측합니다.

환경 예측은 위치 토큰 집합에서, 행동 선택은 네 행동 토큰 집합에서 확률을 정규화합니다. 벽으로 향하는 행동도 선택할 수 있으며 환경이 충돌을 처리합니다. 모델은 매번 전체 지도와 현재 위치를 받고 다음 행동 하나를 출력합니다.

## 4. 사전학습: 환경 규칙 이해

### 학습 절차

1. 학습 지도에서 일반 바닥 또는 미끄러운 바닥의 현재 위치와 행동을 무작위로 고릅니다.
2. 환경에서 다음 위치를 한 번 샘플링해 전이 기록을 만듭니다.
3. 지도·현재 위치·행동을 입력하고 실제 다음 위치의 cross-entropy로 학습합니다.
4. 모델을 `pretrain.pt`에 저장합니다.

### 얻고자 하는 능력

- 벽이나 지도 밖으로 향하면 현재 위치에 남는 규칙 이해.
- 일반 바닥에서 지정 방향으로 움직이는 규칙 이해.
- 미끄러운 바닥에서 여러 다음 위치가 가능한 규칙 이해.
- 구멍과 목표 위치로 이동할 확률 예측.

### 완료 후 확인

`launch_world` 화면에서 행동을 선택하고 모델의 예측 분포와 환경의 정확한 전이확률을 비교하세요. 한 걸음씩 실행해 실제 다음 위치를 확인합니다. 파란 표시는 이동 전 위치, 주황색 테두리는 이동 후 위치입니다.

평가표에서 TV distance와 KL은 낮을수록, 실제 가능한 다음 위치에 부여한 확률인 `exact_support_probability`는 높을수록 좋습니다.

## 5. SFT: 목표를 향한 기본 행동

### 학습 절차

1. `pretrain.pt`의 공유 모델을 불러옵니다.
2. 벽과 구멍을 막힌 칸으로 취급하고 미끄러짐을 끈 조건에서 BFS 경로를 구합니다.
3. 목표에 도달할 수 있는 각 비종료 위치에서 BFS의 첫 행동을 정답으로 사용합니다. 여러 최단 경로는 고정된 행동 순서로 선택합니다.
4. 다음 행동의 cross-entropy로 학습하고 `sft.pt`에 저장합니다.

### 얻고자 하는 능력

- 지도와 목표를 읽고 다음 행동 선택.
- 벽과 구멍을 피하며 목표로 이동.
- 현재 위치가 달라지면 그 위치에서 목표로 향하는 행동 선택.

BFS는 이동 횟수가 가장 짧은 경로를 제공합니다. GRPO에서는 여기에 미끄러짐에 따른 추락 위험과 실제 이동 비용을 반영합니다.

### 완료 후 확인

`launch_navigation`으로 SFT 모델을 실행하세요. 미끄러짐을 끈 상태에서 이동을 확인하고, 미끄러짐을 켠 뒤 **지도 초기화**를 눌러 다시 실행합니다. 평가표에서 도착률·추락률·시간초과율·평균 보상·이동 횟수·충돌 수를 비교합니다. 모델의 실행 행동은 argmax로 선택합니다.

## 6. GRPO: 실제 위험과 이동 비용 고려

### 학습 절차

1. `sft.pt`를 초기 정책으로 불러오고 같은 모델을 동결 reference로 보관합니다.
2. 지도 하나에서 후보 에피소드 4개를 실행합니다. 매 이동마다 실제 현재 위치를 관측하고 행동을 샘플링합니다.
3. 각 후보가 받은 환경 보상을 합산합니다.
4. 그룹 내 보상 평균과 표준편차로 advantage를 계산합니다.
5. rollout 당시 행동 확률과 현재 확률의 비율에 PPO clipping을 적용하고 동결 reference와의 KL을 더해 학습합니다.
6. 모델과 reference를 `grpo.pt`에 저장합니다.

같은 그룹의 후보들은 시간별 환경 난수를 공유하고 행동은 각각 샘플링합니다. 다음 업데이트에서는 새 환경 난수를 사용합니다. 학습 신호는 환경의 도착·추락·이동·충돌 보상입니다. BFS와 유한 시간 최적 정책은 평가 기준으로 사용합니다.

보상이 모두 같은 그룹은 업데이트에서 제외합니다. `useful_group_fraction`은 보상 차이가 있어 학습에 사용한 그룹의 비율입니다. 후보별로 행동 손실을 평균하고 microbatch의 gradient를 누적해 optimizer step을 수행합니다. temperature는 행동 샘플링과 학습 확률 계산에 동일하게 적용합니다.

### 얻고자 하는 능력

- 구멍 옆 미끄러운 칸의 추락 위험 반영.
- 성공 가능성과 우회 비용을 함께 고려.
- 미끄러져 위치가 바뀐 뒤 다시 목표를 향하는 행동 선택.

### 완료 후 확인

SFT와 GRPO를 같은 지도와 환경 난수에서 나란히 실행하세요. **한 걸음**으로 행동을 비교하거나 자동 실행으로 목표까지의 이동을 확인합니다. 평가표에서는 도착률·추락률·평균 보상을 함께 비교합니다.

## 7. 평가와 단계 생략 비교

| 지표 | 의미 |
|---|---|
| 도착률 | 시간 제한 안에 목표에 도착한 에피소드 비율 |
| 추락률 | 구멍에 빠진 에피소드 비율 |
| 시간초과율 | 목표 도착·추락 없이 시간 제한에 도달한 비율 |
| 평균 보상 | 이동·충돌·도착·추락 보상 합계의 평균 |
| 성공 시 이동 수 | 목표에 도착한 에피소드의 평균 행동 수 |
| 전체 이동 수·충돌 수 | 모든 에피소드의 행동 수·충돌 수 평균 |

BFS는 실제 현재 위치에서 매번 다시 계획합니다. `optimal`은 실제 전이확률·보상·남은 행동 수를 반영한 유한 시간 dynamic programming 정책입니다. 같은 비교에서는 지도·시행·시간별 환경 난수를 공유합니다.

학습 지도 seed는 `seed`, 검증 지도는 `1,000,000 + seed`, 테스트 지도는 `2,000,000 + seed`부터 시작합니다. 단계별 확인에는 검증 지표를 사용하고 세 단계 학습을 마친 뒤 최종 테스트를 실행합니다.

| 비교 | 실행 방법 | 확인할 항목 |
|---|---|---|
| 전체 흐름과 사전학습 생략 | `RUN_WITHOUT_PRETRAIN = True`: 무작위 초기화 → SFT → GRPO | 같은 후속 학습 예산에서 도착률·보상·학습 시간 비교 |
| 전체 흐름과 SFT 생략 | `RUN_WITHOUT_SFT = True`: 사전학습 → GRPO | 초기 성공률·유용한 보상 그룹 비율 비교 |
| SFT와 SFT → GRPO | 3단계 평가 셀 실행 | 미끄러짐 환경의 도착률·추락률·평균 보상 비교 |

생략 실험은 `without_pretrain`, `without_sft` 하위 폴더에 저장합니다. 지도 수와 학습 예산은 설정 파일에서 지정합니다.

## 8. 저장·재개·수정

기본 업데이트 수는 사전학습 1,500회, SFT 2,000회, GRPO 250회입니다. `configs/t4.json`의 각 단계에서 `steps`, `batch_size` 또는 `prompts`, `learning_rate`를 조정합니다.

체크포인트는 모델·설정·optimizer·GradScaler·난수 상태·학습 기록을 포함합니다. GRPO는 동결 reference도 포함합니다. 중단한 단계를 재개할 때는 같은 설정과 출력 폴더에서 `RESUME = True` 또는 CLI의 `--resume`을 사용하세요. 설정을 바꾸면 새 출력 폴더에서 시작합니다. CLI의 `--steps`는 도달할 총 업데이트 수입니다.

Colab의 기본 출력 폴더는 `/content/maze_runs/t4`입니다. Drive 저장은 학습 전에 `USE_DRIVE = True`로 선택합니다. 내려받은 ZIP을 출력 폴더에 복원한 뒤 평가 셀을 실행하면 저장된 모델을 다시 사용할 수 있습니다.

환경과 학습 로직은 `maze_training/`, 실험 설정은 `configs/`에서 수정하세요. 노트북 셀의 원본은 `scripts/create_notebook.py`입니다. 이 파일을 수정하고 `python scripts/create_notebook.py`를 실행해 `notebooks/Maze_Training.ipynb`를 갱신합니다.
