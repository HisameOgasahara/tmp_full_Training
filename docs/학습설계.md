# 비용이 다른 미로의 규칙과 학습 구조

## 1. 목적

벽을 피해 목표에 도착하면서 총 이동 비용이 작은 경로를 선택합니다. 사전학습은 환경의 이동·비용 규칙, SFT는 BFS 길찾기, PPO는 도착 보상과 이동 비용을 학습합니다. PPO는 post-training의 RL 단계입니다.

## 2. 환경

| 항목 | 기본 규칙 |
|---|---|
| 크기 | 5×5 또는 7×7 |
| 관측 | 전체 지도와 현재 위치 |
| 행동 | 위·오른쪽·아래·왼쪽 |
| 일반 바닥·목표 진입 | 비용 1 |
| 늪 진입 | 비용 4 |
| 벽·지도 밖 | 제자리에 남고 현재 칸 비용에 충돌 비용 2 추가 |
| 이동 보상 | 비용 × −0.1 |
| 목표 도착 | 보상 +5 추가, 종료 |
| 시간 제한 | 64회 행동, 도착하지 못하면 시간초과 |

비용은 도착한 칸을 기준으로 계산합니다. 비용 12의 경로로 도착하면 총보상은 3.8입니다. 일반 바닥에서 벽에 부딪히면 비용 3, 보상 −0.3입니다. 이동 방향은 항상 선택한 행동과 같습니다.

지도에는 벽과 늪을 무작위 배치합니다. BFS 경로와 Dijkstra 경로를 구해, 최소 비용 경로가 BFS 경로보다 길고 비용 차이가 2 이상이며 시간 제한 안에 도착하는 지도를 채택합니다. 벽은 지도 크기 이상의 개수를 요구합니다. 실행 화면의 고정 예시는 상단 늪 지름길과 아래 일반 우회로를 갖습니다.

BFS는 이동 횟수를 최소화하고 Dijkstra는 누적 비용을 최소화합니다. 두 알고리즘 모두 현재 위치에서 다시 계획합니다. 지도 생성과 평가에서 Dijkstra를 사용하고, 모델 학습의 정답 행동은 BFS로 만듭니다.

## 3. 모델

4층 causal Transformer, 차원 128, attention head 4개, MLP 배수 4를 사용합니다. 어휘는 타일 4개·위치 49개·행동 4개·지도 크기 8개·작업 및 질의 3개로 총 68개입니다. 입력은 최대 54토큰입니다.

| 작업 | 입력 | 출력 |
|---|---|---|
| 환경 예측 | 작업·지도 크기·지도·현재 위치·행동·질의 | 다음 위치와 이동 비용 |
| 행동 선택 | 작업·지도 크기·지도·현재 위치·질의 | 네 행동의 확률과 현재 위치의 가치 |

다음 위치·행동 출력은 공유 토큰 임베딩과 연결됩니다. 비용과 가치는 마지막 질의 표현에서 각각 scalar head로 예측합니다. 비용 출력은 늪 비용으로 나눈 값이며 평가·화면에서 원래 단위로 환산합니다. 가치 출력은 예상 누적 보상이고 초기 가중치는 0입니다.

## 4. 사전학습

비종료 위치와 행동을 무작위 선택해 실제 다음 위치와 비용을 기록합니다. 다음 위치 cross-entropy와 정규화 비용 smooth-L1 손실을 합쳐 공유 모델을 학습합니다.

얻고자 하는 능력은 벽 충돌 후 위치 유지, 일반 바닥과 늪의 이동 비용 구분, 지도와 행동으로 다음 위치 예측입니다. `next_position_accuracy`와 `cost_mae`로 평가합니다.

## 5. SFT

사전학습 모델에서 시작합니다. 목표에 도달 가능한 각 위치에서 BFS의 첫 행동을 정답으로 학습합니다. 행동 cross-entropy로 벽을 피해 목표로 향하는 능력을 익힙니다. BFS는 늪 비용을 경로 선택에 반영하지 않습니다.

기본 업데이트는 4,000회입니다. 추가 학습 셀의 `SFT_TOTAL_STEPS`는 기존 학습을 포함한 총 업데이트 수입니다.

## 6. PPO

SFT의 행동 출력을 이어받고 가치 출력을 함께 학습합니다. 지도별 에피소드를 행동 샘플링으로 실행하며, 매 행동의 보상과 가치 예측을 기록합니다. 목표 도착 또는 시간 제한까지 완결된 에피소드 16개를 한 업데이트의 데이터로 사용합니다.

GAE는 각 행동의 보상·다음 위치 가치·현재 위치 가치를 이용해 advantage를 계산합니다. 기본 `gamma`는 1, `gae_lambda`는 0.95입니다. 목표와 시간초과는 이 유한 에피소드의 끝이므로 이후 가치는 0입니다. 에피소드별 GAE를 구한 뒤 전체 행동의 advantage를 정규화합니다.

PPO는 rollout 당시와 현재 행동 확률의 비율을 clipping해 정책 손실을 계산합니다. 가치 출력은 GAE return에 맞춰 학습하고 entropy 항으로 탐색을 유지합니다. 기본 clipping은 0.2, 학습률은 0.00001, epoch는 2입니다. minibatch마다 업데이트하며 이전 정책과의 추정 KL이 0.02를 넘으면 해당 데이터의 남은 업데이트를 멈춥니다.

PPO는 환경 보상을 학습 신호로 사용합니다. 목표는 도착을 유지하면서 비싼 늪을 우회해 총비용을 줄이는 것입니다. 실행 화면과 평가는 argmax 행동을 사용합니다.

## 7. 평가와 모델 선택

| 지표 | 의미 |
|---|---|
| 도착률 | 시간 제한 안에 목표 도착 |
| 시간초과율 | 목표 도착 없이 종료 |
| 평균 보상 | 도착 보상에서 이동·충돌 비용을 뺀 값의 전체 평균 |
| 성공 시 비용 | 도착한 경로의 총비용 평균 |
| 최소 비용 대비 초과 | 도착한 경로 비용에서 같은 지도의 Dijkstra 비용을 뺀 평균 |
| 성공 시 이동 수 | 도착한 경로의 행동 수 평균 |
| 충돌 수 | 모든 경로의 평균 충돌 수 |

도착률과 평균 보상을 먼저 확인하고 성공한 경로의 비용을 비교합니다. 결정적 환경이므로 같은 지도를 한 번씩 평가합니다. 학습 지도 seed는 `seed`, 검증은 `1,000,000 + seed`, 테스트는 `2,000,000 + seed`부터 시작합니다.

PPO는 50회마다 검증합니다. 시작 SFT를 포함해 도착률이 높은 모델을 선택하고 동점이면 평균 보상으로 선택합니다. `ppo_refinement/selected_policy.pt`에 모델, `selection.json`에 출처·PPO 업데이트 수·검증 지표를 보관합니다. 구간 모델과 검증 기록도 각각 저장합니다. 최종 테스트는 선택을 마친 뒤 별도 지도에서 실행합니다.

선택적 비교는 사전학습 생략과 SFT 생략입니다. 후속 단계의 실제 업데이트 수를 맞추고 별도 폴더에 저장합니다. SFT 생략은 사전학습 모델의 행동 출력에서 PPO를 시작합니다.

## 8. 저장과 수정

체크포인트에는 모델·설정·optimizer·GradScaler·난수 상태·학습 기록을 저장합니다. 같은 설정과 출력 폴더에서 재개합니다. 이전 미끄러짐 환경의 체크포인트는 이번 토큰과 출력 구조에 맞지 않으므로 새 모델로 시작합니다.

환경·학습 로직은 `maze_training/`, 학습 예산과 비용은 `configs/`에서 수정합니다. 노트북 셀은 `scripts/create_notebook.py`에서 수정하고 `python scripts/create_notebook.py`로 생성합니다.
