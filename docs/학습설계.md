# 미끄러운 미로의 규칙과 단계별 학습 목표

## 1. 과제

지도 전체와 현재 위치를 보고 상하좌우 중 한 행동을 선택해 목표에 도착합니다. 벽은 통과할 수 없고 구멍은 실패로 종료됩니다. 미끄러운 바닥에서는 의도한 방향과 실제 이동 방향이 달라질 수 있습니다. 모델은 매 이동 후 실제 위치를 다시 받습니다.

짧은 경로가 구멍 옆 미끄러운 칸을 지나면 실패 위험이 생깁니다. 더 긴 우회 경로가 실제 성공률과 평균 보상에서 유리할 수 있습니다. 이러한 차이를 통해 환경 규칙 학습, 목표 행동 모방, 실제 결과 최적화를 구분합니다.

## 2. 환경 규칙

| 항목 | 기본 설정 |
|---|---|
| 지도 크기 | 5×5 또는 7×7 |
| 관측 | 전체 지도, 지도 크기, 현재 위치. 목표는 지도 타일로 표시 |
| 행동 | 위·오른쪽·아래·왼쪽 |
| 출발점·목표 | 무작위 지도는 왼쪽 아래 출발, 오른쪽 위 목표 |
| 벽·지도 밖 | 제자리에 남고 충돌 비용 적용 |
| 구멍 | 이동 즉시 실패 종료 |
| 목표 | 이동 즉시 성공 종료 |
| 미끄러짐 | **출발 칸이 미끄러운 바닥일 때** 70%는 지정 방향, 15%씩 양옆 방향 |
| 시간 제한 | 최대 64회 행동 후 시간초과 종료 |
| 한 번의 이동 보상 | 항상 −0.01 |
| 추가 보상 | 목표 +1, 구멍 −1, 충돌 −0.02 |

확률과 보상은 `configs/t4.json`에서 바꿉니다. 예를 들어 10회 이동 후 도착하면 총 보상은 충돌이 없을 때 0.90입니다. 64회 동안 도착하지 못하고 충돌도 없다면 −0.64입니다. 구멍에 빠지는 정책과 제자리에서 시간을 보내는 정책을 모두 평가해야 합니다.

지도는 벽·구멍·미끄러운 칸을 무작위 배치한 뒤, 미끄러짐을 무시하면 출발점에서 목표까지 안전한 경로가 있는 경우만 사용합니다. 완전 미로처럼 경로가 하나인 구조를 강제하지 않습니다. 모든 무작위 지도에서 위험한 지름길과 안전한 우회로가 반드시 존재하는 것은 아닙니다.

실행 화면의 ‘위험한 지름길 예시’는 상단의 미끄러운 길 아래에 구멍을 둔 별도 고정 지도입니다. 고정 예시는 설명용이며 학습·검증·테스트 지표에 포함하지 않습니다. 그 화면에서 잘 움직이는 것만으로 일반화를 판단하지 않습니다.

## 3. 공유 모델과 입력

4층 causal Transformer decoder를 모든 단계에서 공유합니다. 차원 128, attention head 4개, MLP 배수 4입니다. 학습용 언어모델 가중치를 가져오지 않고 무작위 초기화합니다.

| 작업 | 입력 | 예측 |
|---|---|---|
| 환경 예측 | 작업 토큰, 지도 크기, 지도 타일, 현재 위치, 행동, 질의 토큰 | 다음 위치 토큰 |
| 행동 선택 | 작업 토큰, 지도 크기, 지도 타일, 현재 위치, 질의 토큰 | 4개 행동 토큰 중 하나 |

작은 지도는 최대 크기까지 벽 토큰으로 채웁니다. 위치 토큰은 최대 크기 격자의 행·열을 한 인덱스로 표현합니다. 입력 길이는 T4 설정에서 최대 54토큰입니다. 마지막 질의 토큰의 출력만 계산해 불필요한 전체 시퀀스 출력 메모리를 줄입니다.

환경 예측은 위치 토큰 집합 안에서, 행동 선택은 네 행동 토큰 집합 안에서 확률을 정규화합니다. 정책의 벽 충돌 행동을 미리 제거하지 않습니다. 움직임의 타당성은 환경 결과를 통해 배웁니다. 추론 중 목표 경로를 모델에 전달하지 않습니다.

모델은 매 단계 지도와 현재 위치를 다시 받습니다. 과거 경로를 기억하는 부분 관측 과제가 아니며, causal 구조를 사용하더라도 긴 경로 전체를 한 번에 생성하지 않습니다.

## 4. 사전학습: 환경 규칙 이해

### 데이터와 목표

학습 지도에서 비종료 위치와 행동을 무작위 선택하고 환경에서 다음 위치를 한 번 샘플링합니다. 예제는 지도·현재 위치·행동·실제 다음 위치의 전이 기록입니다. BFS의 정답 행동은 사용하지 않습니다. 다음 위치의 categorical cross-entropy를 최소화합니다.

### 얻고자 하는 능력

- 벽이나 지도 밖으로 향하면 현재 위치에 남는다는 규칙.
- 일반 바닥에서는 지정 방향으로 움직인다는 규칙.
- 미끄러운 바닥에서는 여러 다음 위치가 가능하다는 규칙.
- 지도상의 구멍·목표 위치로 이동할 가능성 예측.

실패 여부를 별도 출력으로 학습하지 않습니다. 다음 위치 예측 분포와 지도상의 구멍 위치를 함께 읽어 추락 확률을 계산할 수 있습니다.

### 완료 후 실행과 평가

`launch_world` 화면에서 행동을 지정하고 모델의 확률과 환경의 정확한 전이확률을 나란히 봅니다. 실제 한 걸음을 실행해 결과를 확인합니다. 아직 목표 행동을 선택하도록 학습하지 않았으므로 정책 이동 화면은 사용하지 않습니다.

검증 지도에서 TV distance, 정확한 분포에서 모델 분포로의 KL, 실제로 가능한 다음 위치에 부여한 확률을 측정합니다. 앞의 두 지표는 낮을수록 좋고 마지막 지표는 높을수록 좋습니다. 다음 위치 샘플 정확도는 확률적 결과 때문에 100%가 필수 조건이 아닙니다. 지도 밖이나 벽에 둔 확률도 확인합니다.

## 5. SFT: 목표를 향한 기본 행동

### 데이터와 목표

같은 학습 지도에서 BFS로 목표까지의 안전한 최단 경로를 구합니다. 벽과 구멍을 막힌 칸으로 취급하고 미끄러짐은 무시합니다. 목표에 도달할 수 있는 모든 비종료 위치에서 첫 행동을 학습합니다. 여러 최단 경로가 있으면 고정된 행동 순서로 하나를 선택합니다.

사전학습 체크포인트의 공유 모델을 불러와 다음 행동 cross-entropy로 학습합니다. 출발점 경로의 위치뿐 아니라 다른 도달 가능한 위치도 포함해, 위치가 빗나갔을 때 다시 목표로 향할 기초를 제공합니다.

### 얻고자 하는 능력

- 지도와 목표를 읽고 다음 행동을 고르기.
- 벽과 구멍을 피하며 목표로 이동하기.
- 현재 위치가 바뀌면 거기서 다시 행동을 선택하기.

SFT는 확률적 실패 위험의 기대 비용을 직접 최적화하지 않습니다. 최단 경로 옆 구멍의 위험을 충분히 반영하지 못할 수 있습니다.

### 완료 후 실행과 평가

`launch_navigation`으로 SFT 모델을 실행합니다. 같은 지도를 미끄러짐을 끈 상태와 켠 상태에서 각각 확인합니다. 검증 지도에서 도착률, 추락률, 시간초과율, 평균 보상, 이동 횟수, 충돌 수를 측정합니다. 실제 생성 행동은 argmax로 고릅니다.

BFS도 실제 현재 위치에서 매번 다시 계획합니다. 처음 받은 경로만 끝까지 따라가는 약한 기준으로 만들지 않습니다. 지도와 환경 난수는 모델과 BFS에 동일하게 적용합니다.

## 6. GRPO: 실제 위험과 이동 비용 고려

### 시행과 보상

SFT 모델을 초기 정책으로 사용합니다. 지도 하나에서 후보 에피소드 4개를 실행하고, 각 이동 때 모델이 실제 관측 위치를 받아 행동을 샘플링합니다. 후보의 마지막 점수는 에피소드 동안 환경 보상의 합입니다. 전이 확률·BFS 행동·최적 행동을 정책 정답으로 주지 않습니다.

같은 그룹 안에서는 시간별 환경 난수를 공유합니다. 후보 행동은 독립적으로 샘플링하되 미끄러짐 운만으로 보상 순위가 크게 바뀌는 일을 줄입니다. 다른 업데이트에서는 새로운 환경 난수를 사용합니다.

### 업데이트

그룹의 보상 평균과 표준편차로 advantage를 구하고, rollout 때 기록한 행동 확률과 현재 확률의 비율에 PPO clipping을 적용합니다. SFT 초기 정책을 동결한 reference와의 categorical KL을 네 행동 전체에 대해 계산합니다. critic과 별도 보상 모델은 없습니다.

같은 그룹의 모든 보상이 같으면 그 그룹을 업데이트에서 제외합니다. 이러한 그룹의 비율은 `useful_group_fraction`으로 출력합니다. 그룹을 만들었다가 모두 같으면 해당 업데이트는 건너뛰고 다음 유한한 학습 반복으로 넘어가므로 무한 재시도하지 않습니다.

후보별 평균 행동 손실을 사용합니다. 긴 실패 경로가 행동 수 때문에 더 큰 가중치를 받지 않도록 각 행동 손실에 해당 경로 길이의 역수를 곱합니다. microbatch마다 gradient를 누적한 뒤 한 번의 optimizer step을 수행합니다. temperature는 행동 샘플링과 학습 확률 양쪽에 동일하게 적용합니다.

### 얻고자 하는 능력

- 구멍 옆 미끄러운 칸을 지나가는 위험을 반영하기.
- 성공 가능성과 우회 비용을 함께 고려하기.
- 미끄러져 위치가 바뀐 뒤 다시 목표를 향하기.

### 완료 후 실행과 평가

SFT와 GRPO를 같은 지도·환경 난수로 나란히 실행합니다. 그림 한 번의 차이보다 여러 지도에서 반복 실행한 도착률·추락률·평균 보상을 우선 봅니다. 성공 시 평균 이동 수만 보면 실패가 많은 정책이 좋아 보일 수 있으므로 전체 지표를 함께 읽습니다.

유한 시간 dynamic programming으로 같은 환경·보상·시간 제한에서의 최적 정책도 계산합니다. 최적 정책은 평가에만 사용하고 학습 정답에 넣지 않습니다. 확률적 환경에는 유일한 정답 경로가 없지만, 환경 규칙과 성공 판정은 정확하게 계산할 수 있습니다.

## 7. 단계의 효과 확인

세 단계 모두가 절대적으로 필수라는 전제로 결과를 해석하지 않습니다. 작은 지도에서는 충분한 SFT나 RL만으로도 좋은 정책을 얻을 수 있습니다. 사전학습은 환경 규칙을 미리 배워 이후 데이터와 시행 비용을 줄이는지, SFT는 초기 성공 시행을 만들어 RL 학습을 돕는지 확인하는 단계입니다.

| 비교 | 확인할 질문 |
|---|---|
| 전체 흐름과 사전학습 생략 | 같은 SFT·RL 예산에서 도착률·보상 또는 학습 속도가 나아지는가? |
| 전체 흐름과 SFT 생략 | 초기 성공률과 유용한 보상 그룹 비율이 나아지는가? |
| SFT와 SFT→GRPO | 실제 미끄러짐 환경에서 도착률·평균 보상이 개선되는가? |

노트북 끝의 선택적 비교 셀에 두 생략 실험이 있습니다. SFT 생략 실험은 사전학습 모델의 미학습 행동 출력을 초기 정책으로 사용합니다. 학습 예산은 유지하지만 전체 계산량은 다르므로, 업데이트 수와 실행 시간도 함께 기록합니다. 한 seed만으로 일반적인 우월성을 주장하지 않습니다.

## 8. 데이터 분리와 재현

학습 지도 seed는 `seed`부터, 검증 지도는 `1,000,000 + seed`부터, 테스트 지도는 `2,000,000 + seed`부터 사용합니다. 각 split의 지도 수는 1,000,000보다 작게 제한합니다. seed는 겹치지 않지만 우연히 동일한 지도 모양이 생성될 가능성까지 제거하지는 않습니다.

단계별 실행 확인에는 검증 지표를 사용합니다. 최종 테스트는 세 단계 학습을 마친 뒤 실행하며 학습 경로 선택에 사용하지 않습니다. 같은 비교 내에서는 동일한 테스트 지도와 난수 시퀀스를 사용합니다. CPU·GPU·PyTorch 버전에 따라 수치와 학습 결과가 달라질 수 있습니다.

## 9. 저장과 실행 범위

각 단계의 모델·설정·optimizer·GradScaler·난수 상태·로그를 함께 저장합니다. GRPO는 동결 reference도 저장합니다. 설정이 다른 체크포인트는 같은 단계 흐름에 섞지 않습니다. 모델과 설정을 바꿨다면 별도의 출력 폴더를 사용합니다.

학습과 추론은 로컬 또는 개인 Colab 런타임에서 수행합니다. 외부 서버나 인증 서비스는 사용하지 않습니다. 공개 저장소에는 코드·설정·빈 출력의 노트북만 올리고 학습 체크포인트·개인 Drive 파일·토큰은 올리지 않습니다. 체크포인트는 `weights_only=True`로 읽습니다. Colab 준비 셀의 네트워크 사용은 요청한 공개 GitHub 저장소와 공개 패키지 설치에 한정됩니다.
